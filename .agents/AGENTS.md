# Project Agent Rules

## Git Workflow & Commit Policy
- **NO Automatic Commits or Pushes**: Never execute `git commit` or `git push` automatically in this or any repository unless explicitly requested by the user in a prompt.
- **Stay on Task Branch**: When tasked with working on a specific branch, switch directly to that target branch and execute there instead of ping-ponging between branches, preventing merge conflict markers.
- Always present changes, test results, and status to the user first.
